# My Shop - Tailwind Practice

A simple Ecobazar-style e-commerce landing page built only with HTML and Tailwind CSS, following the tutorial section-by-section.

## Learning scope
- HTML structure
- Tailwind Play CDN
- Poppins font
- Flexbox and Grid
- Relative/Absolute positioning
- Responsive utility classes
- Hover effects

Images are currently loaded from external image URLs so we can focus on the exact HTML + Tailwind workflow from the video.
